Market Dashboard (Sector + Stock)

Files:
  Sector.py        -> main page (sector dashboard)
  pages/Stock.py   -> second page (stock check)
  core.py          -> shared code
  requirements.txt -> packages

Deploy (free):
1. Make a GitHub account, create a new repository, upload ALL these files
   (keep the pages folder as it is).
2. Go to share.streamlit.io, sign in with GitHub, click New app.
3. Pick your repository, Main file path = Sector.py, click Deploy.
4. Open the link on your phone and Add to Home screen.

Notes: data is Yahoo Finance (unofficial, may be delayed or rate limited).
Not tested on a live server by the author.
